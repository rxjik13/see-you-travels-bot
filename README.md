# 🌍 Бот See You Travels — ежедневные посты в Telegram

Каждый день в **13:00 по Москве** бот сам публикует в ваш канал готовый пост в стиле
See You Travels с красивым фото. Работает бесплатно на GitHub Actions —
ни своего сервера, ни оплаты, ни подписок не нужно.

Тексты уже написаны заранее и лежат в файле `content_bank.py` (24 поста, дальше круг
повторяется). Фото бот подбирает сам под каждую тему.

---

## Что нужно (всё бесплатно)

1. Аккаунт **GitHub** — [github.com](https://github.com)
2. Три «ключа» — они у вас уже есть:
   - `TELEGRAM_TOKEN` — токен бота из @BotFather
   - `TELEGRAM_CHANNEL` — `@see_you_travels`
   - `PEXELS_KEY` — ключ Pexels для фото

Никаких карт и платных сервисов. 🎉

---

## Настройка (разово, ~10 минут)

### Шаг 1. Создайте репозиторий и загрузите файлы
1. На GitHub: **New repository** → имя любое → тип **Private** → **Create repository**.
2. **Add file → Upload files** → перетащите все файлы из этой папки (вместе с папкой `.github`) → **Commit changes**.

### Шаг 2. Добавьте 3 ключа (Secrets)
**Settings → Secrets and variables → Actions → New repository secret**. Добавьте по очереди:

| Имя | Значение |
|-----|----------|
| `TELEGRAM_TOKEN` | токен бота из @BotFather |
| `TELEGRAM_CHANNEL` | `@see_you_travels` |
| `PEXELS_KEY` | ключ Pexels |

### Шаг 3. Проверьте
1. Убедитесь, что бот — **администратор** канала с правом **публикации сообщений**.
2. Вкладка **Actions** → согласитесь включить Actions, если спросит.
3. Выберите **«Ежедневный пост See You Travels»** → **Run workflow** → **Run**.
4. Через минуту в канале появится пост, а в логе будет `Опубликовано в канал ✅`.

Готово — дальше бот постит сам каждый день в 13:00 МСК.

---

## Как что-то поменять
- **Время** — файл `.github/workflows/daily-post.yml`, строка `cron: "0 10 * * *"` (время в UTC, Москва = UTC+3; `0 10 * * *` = 13:00 МСК).
- **Тексты постов** — файл `content_bank.py`. Там понятно расписано, как добавить свой пост.
- **Пауза** — вкладка Actions → workflow → `•••` → Disable workflow.

## Если что-то не так
Вкладка **Actions** → последний запуск → шаг «Опубликовать пост» → прочитайте лог:
- `Telegram 400 ... chat not found` — неверный `@username` канала или бот не админ.
- `Telegram 403 ... not enough rights` — у бота нет права публиковать в канале.
- Пост без фото — не нашлось картинки (текст всё равно выходит).

## 🎉 Второй бот — поиск вечеринок и событий

Рядом с ежедневным постером живёт второй бот: `party_search.py`. Он ищет, где в ближайшее
время проходят вечеринки, DJ-сеты, концерты, beach-party и похожие тусовки в выбранном
городе (по умолчанию — **Каш, Турция**) и присылает дайджест со ссылками в Telegram.

Запускается сам **каждый четверг в ~12:10 по Москве** (файл `.github/workflows/party-search.yml`),
плюс есть кнопка ручного запуска. Показывает только то, чего ещё не было: список уже
опубликованных ссылок хранится в `party_seen.txt`. Если нового ничего нет — молчит.

### Откуда берёт события (бесплатно, без ключей)
1. **Публичные Telegram-каналы** — список в `party_sources.py` → `TELEGRAM_CHANNELS`.
   Бот читает веб-превью `t.me/s/<канал>`, берёт посты за последние 7 дней и отбирает
   те, где есть слова вроде «вечеринка», «party», «DJ», «konser», «festival».
   **Список пуст по умолчанию** — впишите туда username-ы живых каналов Каша
   (найти их можно поиском в Telegram по словам «Каш», «Kaş events»). Приватные группы читать нельзя.
2. **Поиск DuckDuckGo** по запросам из `SEARCH_QUERIES` (русский, английский, турецкий).
   В дайджест попадают только результаты, где упомянут город и есть «вечериночные» слова.

### Умный поиск через ИИ (по желанию, платно)
Если добавить секрет `ANTHROPIC_API_KEY` (ключ Claude API с сайта console.anthropic.com),
бот дополнительно попросит Claude самостоятельно поискать события в интернете и вернуть
аккуратный список: название, дата, место, ссылка и короткое описание по-русски.
Это самый качественный источник, но каждый запуск стоит денег по тарифу API
(обычно центы). Без ключа бот работает только бесплатными способами.

### Настройка
| Что | Где |
|-----|-----|
| Город | `party_sources.py` → `CITY_RU` / `CITY_EN`, или поля при ручном запуске в Actions |
| Куда слать дайджест | секрет `PARTY_CHAT` (например, `@my_private_chat` или числовой id чата). Если не задан — уходит в `TELEGRAM_CHANNEL` |
| Слова-триггеры и стоп-слова | `party_sources.py` → `PARTY_KEYWORDS`, `STOP_WORDS` |
| Telegram-каналы для просмотра | `party_sources.py` → `TELEGRAM_CHANNELS` |
| Расписание | `.github/workflows/party-search.yml`, строка `cron: "10 9 * * 4"` (UTC; четверг). Каждый день — `"10 9 * * *"` |
| Показать всё, включая уже опубликованное | ручной запуск → галочка «Показать всё найденное» |

### Проверить
Вкладка **Actions** → **«Поиск вечеринок See You Travels»** → **Run workflow**.
В логе шага «Найти вечеринки» видно, сколько находок дал каждый источник.
Локально можно посмотреть результат без отправки: `python party_search.py --dry-run`.
